
Facybook Android App
Welcome to the Facybook Android app repository! Facybook is a social networking application inspired by Facebook, developed for this task. This README file provides details about the tasks and functionalities implemented in the Android version of the app.

Task Details
In this task, we were required to develop a static Android application using Java. The app mimics the basic functionalities of a social networking platform, including user registration, authentication, and a feed displaying posts.

Screens Implemented
Login Screen: A simple login screen where users can enter their username and password or navigate to the registration screen.

Registration Screen: Includes fields for username, password, verify password, and nickname.

Feed Screen: Displays a scrolling list of posts retrieved from a JSON file. Users can like, share, and comment on posts. Additionally, there is a toggle button to switch between dark and light mode.

Functionalities Implemented
User registration and authentication.
Displaying a feed of posts with options to like, share, and comment.
Dark and light mode toggle.
Basic form validation for registration and login screens.


Getting Started
To get started with the Facybook Android app, follow these steps:

Download: Clone this repository to a local directory on your machine.

Open Command Prompt: Navigate to the directory where you downloaded the repository using the Command Prompt.

Run App: Type the command npm start to start the development server.

Test the App: You can test the app using an emulator or by connecting a real Android phone to your computer. It's recommended to connect a real phone for the best experience.

Login Credentials: Use the following credentials to log in to the app:

Username: user
Password: password
Night Mode: If you want to experience the night mode feature, change your phone's display settings to night mode. This will change the appearance of the app accordingly.

Emulator: If you prefer to use an emulator, make sure you have Android Studio installed and set up an emulator from the AVD Manager.

Real Phone: To test on a real phone, enable USB debugging on your phone and connect it to your computer via USB. Make sure your phone is recognized by Android Studio and appears in the list of connected devices.

Run: Once the app is running, you can run it on the emulator or your connected phone using Android Studio.
