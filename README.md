## Getting Started

To get started with the Facybook Android app, follow these steps:

1. **Download**: Clone this repository to a local directory on your machine.

2. **Open Command Prompt**: Navigate to the directory where you downloaded the repository using the Command Prompt.

3. **Run App**: Type the command `npm start` to start the development server.

4. **Test the App**: You can test the app using an emulator or by connecting a real Android phone to your computer. It's recommended to connect a real phone for the best experience.

5. **Login Credentials**: Use the following credentials to log in to the app:
   - Username: user
   - Password: password

6. **Emulator**: If you prefer to use an emulator, make sure you have Android Studio installed and set up an emulator from the AVD Manager.

7. **Real Phone**: To test on a real phone, enable USB debugging on your phone and connect it to your computer via USB. Make sure your phone is recognized by Android Studio and appears in the list of connected devices.

8. **Run**: Once the app is running, you can run it on the emulator or your connected phone using Android Studio.

Now you're ready to explore and test the Facybook Android app on your emulator or real device. Enjoy!
